🏰 The Kingdom Roads — MST Solver
An advanced visualization tool developed to solve the Minimum Spanning Tree (MST) problem for the Kingdom of Eldoria. This project implements and compares two fundamental greedy algorithms to connect all kingdom castles with the minimum possible cost.

🚀 Key Features
Dynamic Visualization: Built using the SFML library in C++.  
Interactive GUI: Choose between different algorithms and test cases in real-time.  
Detailed Analysis: Includes complexity comparisons and cycle detection using Union-Find.  
Visual Feedback: Clear distinction between MST roads (Green) and regular roads (Gray).

🛠️ Tech Stack
Language: C++   
Graphics Library: SFML 2.6.1   
IDE: Microsoft Visual Studio 2026

📊 Performance Comparison
Both algorithms successfully produce the same optimal MST result across various test cases, demonstrating the power of greedy strategies in optimization problems.

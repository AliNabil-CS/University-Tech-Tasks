🧟 Zombie Wave Shooter (Unity 3D)
An intense survival game developed using the Unity Engine. Face relentless waves of zombies,
manage your resources, and test your survival skills in this action-packed project! 🎯

🕹️ Key Features
• Wave System: Dynamic spawning system where difficulty increases over time.   
• Enemy AI: Zombies utilize Unity's NavMesh or custom pathfinding logic to track the player.   
• Combat Mechanics: Smooth shooting system, projectile physics, and hit detection.   
• User Interface: Interactive HUD showing health, score, and wave progress.

🛠️ Tech Stack & Concepts
• Engine: Unity 2022+ 🎮
• Language: C# (Object-Oriented Programming) 💻
• Components: Rigidbody Physics, Colliders, Raycasting, and Prefabs
• Architecture: State machines for player and enemy behavior.

🎮 Installation & Controls
1. Download the repository.
2. Open the project in Unity Hub.
3. Controls: * WASD to move.
   • Left Mouse Button to shoot.
   • R to reload.
